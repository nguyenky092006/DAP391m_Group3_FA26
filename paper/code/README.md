# Reproduction code for the acoustic-cue study

This directory contains the code used for the three research questions reported
in `../main.tex`:

- RQ1: controlled pitch, energy, and duration interventions;
- RQ2: matched four-system sensitivity analysis and robustness checks;
- RQ3: exploratory accent-stratified F0 sensitivity analysis.

It intentionally excludes ViSEC audio, derived audio, checkpoints, cached model
files, predictions, and generated artifacts. The official ViSEC distribution
must be obtained separately and used in accordance with its license.

## Expected local layout

Run commands from this directory. Place the local corpus and split manifest as
follows:

```text
code/
  data/
    splits.csv
    raw/visec_staged/
      data.csv
      wav/
  checkpoints/
  artifacts/
```

The scripts use the shared constants and paths in `cf_ser/config.py`. The label
order is `happy`, `neutral`, `sad`, `angry`, the sample rate is 16 kHz, and the
main random seed is 2025. Seeds 2026 and 2027 are also used for the reported
three-member ensembles.

## Environment

Python 3.10 or 3.11 and a CUDA-capable PyTorch installation are recommended for
training Wav2Vec2. Install the remaining dependencies with:

```bash
python -m pip install -r requirements.txt
```

## Main workflow

The scripts are preserved as the research pipeline used to create the reported
artifacts. They are intentionally separated by analysis stage rather than
presented as a single production CLI.

1. Prepare the local manifest and train the compact models:

   ```bash
   python run_pipeline.py prepare
   python optimize_models.py
   python run_ensemble_experiment.py
   ```

2. Fine-tune Wav2Vec2 on the same split for seeds 2025, 2026, and 2027:

   ```bash
   python train_wav2vec2.py --seed 2025 --learning-rate 3e-5
   python train_wav2vec2.py --seed 2026 --learning-rate 3e-5
   python train_wav2vec2.py --seed 2027 --learning-rate 3e-5
   ```

3. Run the four-model RQ2 analysis. Pass the three resulting checkpoint
   directories explicitly:

   ```bash
   python run_rq2_4models.py --wav2vec-checkpoints <seed2025> <seed2026> <seed2027>
   python run_rq2_calibration_robustness.py
   python analyze_rq2_all_neutral_paired.py
   ```

4. Run the controls and supporting audits:

   ```bash
   python run_fixed_semitone_audit.py
   python run_pitch_dose.py
   python analyze_pitch_dose_controlled.py
   python analyze_f0_confound.py
   python run_preprocessing_audit.py
   python train_prosody_no_f0_ablation.py
   python run_intervention_validity.py
   ```

5. Run the exploratory RQ3 accent analysis with the same Wav2Vec2 ensemble:

   ```bash
   python run_rq3_accent.py --wav2vec-checkpoints <seed2025> <seed2026> <seed2027>
   ```

6. Materialize and validate the consolidated result tables:

   ```bash
   python finalize_rq1_rq2.py
   python analyze_reviewer_upgrade.py
   python finalize_reviewer_hardening.py
   python validate_results.py
   ```

Some later-stage scripts consume artifacts generated by earlier stages. If a
stage reports a missing file, run the producing stage first rather than editing
the statistical inputs by hand.

## Scope and interpretation

The transformations are diagnostic perturbations, not emotional voice
conversion. The code measures model probability sensitivity and class flips; it
does not establish human-perceived anger, naturalness, lexical-tone preservation,
or causal effects of architecture alone. The RQ3 script uses the accent metadata
represented in the local ViSEC copy and should be interpreted with the sampling
limitations stated in the manuscript.
