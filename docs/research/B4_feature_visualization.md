# B4 Feature and Advanced Visualization

The feature package contains 4,992 five-channel temporal prosody artifacts and a 174-dimensional M1 summary table. The three advanced figures are a log-F0 violin plot, standardized multi-prosody heatmap, and t-SNE projection of 2,000 deterministic samples.

The interactive dashboard is `reports/dashboard/b4_feature_dashboard.html`. Model normalization remains train-only; full-data visualization transforms are exploratory and never reused for training.
