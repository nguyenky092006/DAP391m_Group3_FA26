# B2 Data Understanding

The pinned ViSEC release contains 5,280 source records; 4,992 are eligible and 288 remain traceable as excluded. The eligible set contains 147 speaker IDs. No accent, gender, or speaker identifier is used as a model input.

Machine-readable outputs are in `reports/foundation/b2_data_dictionary.csv`, `b2_distributions.csv`, and `b2_data_quality_summary.json`. Raw audio is unchanged.
